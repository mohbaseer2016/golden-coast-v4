# منصة جولدن كوست لإدارة العمليات

نسخة تشغيل محلية أولى مكتملة لمسار الفاتورة:

الموارد ← المخزن ← السائق ← المرتجع إن وجد ← الموارد ← الأرشيف

## التشغيل على ويندوز

1. ثبّت Python 3.12.
2. افتح PowerShell داخل مجلد المشروع.
3. نفّذ:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

4. افتح المتصفح على:

```text
http://localhost:8000
```

## الحسابات التجريبية

- الإدارة: `admin / 1234`
- الموارد: `hr1 / 1234`
- المخزن: `wh1 / 1234`
- السائق: `driver1 / 1234`

غيّر كلمات المرور والسر الموجود في `app/security.py` قبل التشغيل الفعلي.

## التشغيل بواسطة Docker

```bash
docker compose up --build
```

ثم افتح `http://localhost:8000`.

## الاستخدام من الجوال داخل نفس شبكة الشركة

1. شغّل النظام على كمبيوتر الشركة.
2. اعرف عنوان IP للكمبيوتر، مثل `192.168.1.50`.
3. افتح من الجوال:
   `http://192.168.1.50:8000`
4. يمكن إضافة الموقع إلى الشاشة الرئيسية ليظهر مثل تطبيق.

## الموجود

- واجهة عربية RTL.
- الجوال والكمبيوتر.
- صلاحيات الإدارة والموارد والمخزن والسائق.
- إدخال رقم الفاتورة وتعيين السائق.
- تحميل كامل/ناقص/رفض.
- كامل/جزئي/رفض/مؤجل.
- تصوير الاستلام والمرتجع.
- مطابقة كمية المرتجع.
- استلام أصل الفاتورة والإغلاق.
- البحث والأرشيف.
- إدارة المستخدمين.
- سجل تدقيق Audit Log.
- PWA أساسي.
- Docker.

## ملاحظات ما قبل الإنتاج

- غيّر مفتاح الجلسة في `app/security.py`.
- ضع النظام خلف HTTPS.
- استخدم PostgreSQL بدل SQLite إذا زاد عدد المستخدمين كثيرًا.
- خذ نسخة احتياطية يومية من قاعدة البيانات ومجلد uploads.
