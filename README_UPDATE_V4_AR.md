# تحديث V4 — صلاحيات التعديل والحذف

## الصلاحيات
- الإدارة: تعديل وحذف أي فاتورة، وتغيير حالتها، وحذف الحركات.
- الموارد: تعديل رقم الفاتورة والعميل والملاحظات قبل اعتماد المخزن.
- المخزن: تعديل السائق والسيارة وبيانات التحميل قبل اعتماد السائق.
- السائق: تعديل نتيجة التسليم قبل اعتماد الطرف التالي.
- بعد اعتماد الطرف التالي تُقفل المرحلة السابقة تلقائيًا.

## طريقة التحديث
1. أوقف النظام: Ctrl + C
2. خذ نسخة احتياطية من مجلد المشروع.
3. فك ضغط V4 وانسخ ملفاته فوق المشروع القديم واختر Replace.
4. لأن V3 وV4 لهما نفس هيكل قاعدة البيانات، لا تحذف golden_coast.db.
5. فعّل البيئة:
   .\.venv\Scripts\Activate.ps1
6. نفّذ:
   pip install -r requirements.txt
7. شغّل:
   python run.py
8. حدّث المتصفح بقوة:
   Ctrl + Shift + R

## ملاحظة
حذف الفواتير والحركات نهائي، لذلك خذ نسخة احتياطية قبل الحذف.
