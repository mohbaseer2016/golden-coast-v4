# تحديث V3 — شركة جولدن كوست التجارية

## الجديد
- صفحة السيارات تظهر للإدارة.
- إضافة السيارات من الإدارة.
- معين يختار السائق والسيارة عند تحميل الفاتورة.
- إضافة خيار سائق خارجي.
- السائق الخارجي لا يملك حساب دخول.
- فاتورة السائق الخارجي تنتقل للموارد بعد التحميل.
- الموارد ترفع صورة الاستلام المرسلة من السائق الخارجي ثم تغلق الفاتورة.
- تعديل بيانات المستخدم: الاسم، اسم المستخدم، رمز الدخول، الدور، رمز السائق، الجوال، التفعيل والإيقاف.
- متوافق مع Python 3.13.

## طريقة التحديث
1. أوقف النظام بـ Ctrl + C.
2. خذ نسخة احتياطية من مجلد المشروع القديم.
3. فك ضغط V3.
4. انسخ الملفات فوق المشروع القديم واختر Replace.
5. احذف golden_coast.db مرة واحدة فقط لأن هيكل قاعدة البيانات تغير.
6. فعّل البيئة:
   .\.venv\Scripts\Activate.ps1
7. ثبّت المتطلبات:
   pip install -r requirements.txt
8. شغّل:
   python run.py
9. افتح:
   http://localhost:8000
