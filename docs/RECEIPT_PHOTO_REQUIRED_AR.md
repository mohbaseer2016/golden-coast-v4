# تحديث صورة الاستلام الإلزامية

- تظهر صورة الاستلام مباشرة داخل نافذة الفاتورة دون عرض الرابط أو تفاصيل الملف.
- زر اعتماد السائق يبقى معطلاً حتى يختار صورة الاستلام.
- الخادم يرفض اعتماد السائق إذا لم تكن هناك صورة استلام، حتى عند محاولة تجاوز الواجهة.
- عند تعديل نتيجة التسليم، تكفي الصورة الموجودة سابقًا، وإلا يلزم رفع صورة جديدة.
