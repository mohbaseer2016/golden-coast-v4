# فتح العمليات بضغطة واحدة — اللابتوب والجوال

تم تحسين فتح الفاتورة بحيث تستجيب من أول ضغطة على زر «فتح» في جميع الجداول الديناميكية.

## ما تم تغييره
- ربط موحد لأزرار فتح الفاتورة عبر Event Delegation، لذلك إعادة رسم الجدول لا تفقد استجابة الزر.
- تعطيل زر الفتح مؤقتًا أثناء الطلب ومنع إرسال طلب مكرر عند الضغط المتكرر على نفس الفاتورة.
- إظهار نافذة «جاري فتح العمليات» فورًا وإعطاء المتصفح فرصة لرسمها قبل طلب الشبكة.
- إضافة endpoint واحد `/api/invoices/{invoice_no}/operations` يعيد بيانات الفاتورة والحركة والفروقات في طلب HTTP واحد بدل ثلاثة طلبات.
- إضافة زر إعادة المحاولة داخل النافذة إذا حدث خطأ شبكة بدل إغلاق النافذة وإجبار المستخدم على البدء من جديد.
- تحسين حالة اللمس والضغط للأزرار على الهاتف مع بقاء نفس السلوك للماوس ولوحة المفاتيح على اللابتوب.

## التحقق
- فحص Python ناجح.
- فحص JavaScript ناجح.
- 50 اختبارًا ناجحًا محليًا، مع stub اختباري لـ passlib لأن الحزمة غير مثبتة في بيئة الاختبار الحالية. هذا الـstub غير موجود داخل النسخة النهائية.
