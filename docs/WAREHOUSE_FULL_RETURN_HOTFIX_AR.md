# إصلاح المرتجع الكامل من المخزن

سبب الخطأ:
حقلا `driver_code` و `driver_name` في قاعدة البيانات الحالية غير قابلين لقيمة NULL.
في حالة المرتجع الكامل لا يوجد سائق، وكانت النسخة السابقة ترسل NULL لهذين الحقلين مما يؤدي إلى فشل قاعدة البيانات ورسالة عامة «حدث خطأ».

الإصلاح:
- حفظ `driver_code` و `driver_name` كسلاسل فارغة عند المرتجع الكامل.
- لا يتم إسناد سائق أو سيارة فعليًا.
- يبقى سبب المرتجع وصورة مستند المرتجع إجباريين.
