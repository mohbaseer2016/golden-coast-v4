# إصلاح التقارير والمستندات والبحث بالزر Enter

- تقرير المرتجعات لم يعد يستخدم كلمة «معلق» العامة؛ يعرض بانتظار المخزن / بانتظار محاسب المبيعات / تم عمل المردود.
- بطاقات تقرير المرتجعات أصبحت خاصة بالمرتجعات بدل بقاء أرقام تقرير سابق.
- رقم الفاتورة في شاشة المستندات أصبح ظاهرًا وقابلًا للفتح.
- أصول الفواتير القديمة تستخدم صورة الأصل الحقيقية أولًا، ثم صورة receipt_photo القديمة كحل توافق فقط إذا كانت النسخة القديمة حفظت الأصل هناك. لا يتم نسخ أو إعادة رفع الصورة.
- الضغط Enter يعمل في حقول البحث الرئيسية والفلاتر البحثية والتقارير والبحث داخل المربعات المنبثقة.
