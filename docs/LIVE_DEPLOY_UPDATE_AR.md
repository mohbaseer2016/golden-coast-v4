# تحديث المستخدمين بعد النشر

- يستخدم النظام RENDER_GIT_COMMIT كرقم نسخة تلقائي لكل Deploy على Render.
- الصفحة الرئيسية وواجهة فحص النسخة ترسل no-cache لمنع بقاء HTML قديم.
- ملفات app.js و app.css تحمل رقم الـ commit في الرابط، فيجلب المتصفح النسخة الجديدة بعد النشر.
- التطبيق يفحص وجود نسخة أحدث بعد 5 ثوانٍ من الفتح، ثم كل دقيقة، وعند العودة للتطبيق أو النافذة.
- لا يتم إجبار المستخدم على إعادة التحميل أثناء تعبئة نموذج. يظهر زر «تحديث الآن» حتى لا تضيع البيانات المدخلة.
- هذا النظام لا يستخدم Supabase Storage ولا يزيد مساحة الصور.
