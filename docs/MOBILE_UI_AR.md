# تحسين الجوال

- تحويل جداول الجوال إلى بطاقات بدون تمرير أفقي.
- إظهار تاريخ الفاتورة وتاريخ التحميل في البطاقات الرئيسية.
- تاريخ التحميل يبقى فارغاً إذا لم يتم التحميل.
- البحث والفلترة والفرز بعناصر لمس كبيرة بعرض الشاشة.
- ربط input و change مع أدوات الفلترة لتحسين Safari وChrome على الجوال.
- تحسين النوافذ المنبثقة والحقول والأزرار للجوال.
