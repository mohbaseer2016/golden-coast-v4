# إصلاح مسار مردود محاسب المبيعات والإقفال المتوازي

سبب المشكلة:
حقول `sales_return_required` و`sales_return_reviewed` كانت موجودة في قاعدة البيانات ومنطق السيرفر، لكنها لم تكن تُرسل داخل `invoice_dict` إلى الواجهة. لذلك شاشة محاسب المبيعات كانت تعرض خطأً «لا يوجد مردود يحتاج محاسب المبيعات» ولا تُظهر زر الاعتماد.

الإصلاح:
- إرسال حالة المردود ومراجعته للواجهة.
- إرسال بيانات استلام أصل الفاتورة (المستخدم والتاريخ) للواجهة.
- لا يستطيع محاسب المبيعات اعتماد المردود قبل استلام ومطابقة المخزن للمرتجع.
- استلام الموارد للأصل لا يغلق الفاتورة إذا كان المردود المحاسبي ما زال معلقًا.
- اعتماد المردود لا يغلق الفاتورة إذا كان أصل الفاتورة أو استلام العميل أو فرق التسليم ما زال معلقًا.
- التسليم لمكتب النقل يبقى معلقًا عند المندوب حتى استلام العميل النهائي.
