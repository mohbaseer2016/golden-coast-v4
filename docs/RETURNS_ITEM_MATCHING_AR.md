# مطابقة المرتجعات حسب الصنف

تم تعديل شاشة أمين المخزن للمرتجع:
- تعرض أصناف المرتجع التي سجلها السائق، مع الصنف والوحدة والكمية.
- لكل صنف يختار أمين المخزن: مطابق / غير مطابق.
- عند عدم المطابقة يجب إدخال الكمية المستلمة فعليًا لذلك الصنف.
- يمكن وجود أكثر من صنف في نفس الفاتورة.
- صورة المرتجع اختيارية لأن إثبات المرتجع قد يكون في نفس صورة الاستلام.
- بعد اعتماد المخزن ينتقل المردود إلى محاسب المبيعات.
- استلام أصل الفاتورة لدى الموارد مستقل عن اعتماد محاسب المبيعات.
