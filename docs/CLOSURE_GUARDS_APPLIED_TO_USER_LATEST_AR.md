# حماية اكتمال الفاتورة — مطبقة على نسخة المستخدم الأخيرة

تم تعديل منطق الإقفال فقط مع الحفاظ على بقية تعديلات النسخة المرفوعة:
- المرتجع المعلق عند المخزن يمنع اكتمال الفاتورة حتى اعتماد المخزن.
- اعتماد مردود المبيعات المطلوب يبقى شرطًا مستقلًا للإقفال.
- التسليم لمكتب نقل يبقى عند المندوب حتى رفع استلام العميل النهائي.
- استلام الموارد لأصل الفاتورة وحده لا يتجاوز أي مسار آخر ما زال معلقًا.
- تحويل عميل إلى عميل يبقى مستثنى من أصل الفاتورة الورقي حسب المسار الموجود.
