# تقرير مراجعة QA للنسخة V6

تم تنفيذ فحوصات بناء وتشغيل ومسارات فعلية على قاعدة SQLite اختبارية منفصلة.

## فحوصات البناء
- Python compile: ناجح.
- JavaScript syntax (`node --check`): ناجح.
- لا توجد معرفات HTML مكررة.
- تمت مطابقة مراجع حقول SQLAlchemy مع الحقول الموجودة في الموديلات.

## المسارات التي تم تشغيلها فعليًا
- تسجيل الدخول والخروج.
- إدارة المستخدمين: إضافة، تعديل، صلاحيات، توقيف/تفعيل، تعطيل.
- إدارة الأصناف: إضافة، تعديل، توقيف/تفعيل، حذف.
- إدارة السيارات: إضافة، تعديل، توقيف/تفعيل، حذف/تعطيل إذا كانت مستخدمة.
- إدارة المناديب: إضافة، توقيف/تفعيل.
- إضافة فاتورة ومنع الرقم المكرر.
- البحث ونافذة مربعات الإحصائيات.
- سائق خارجي: استلام المخزن → استلام الأصل بشكل مستقل → استلام العميل → فرق خارجي → مراجعة الموارد → إغلاق.
- سائق شركة إلى مكتب نقل مع نقص تحميل ثم مرتجع عميل ثانٍ في نفس الفاتورة.
- سائق شركة إلى العميل مباشرة.
- العميل نفسه يستلم.
- المندوب نفسه يوصل.
- حساب مندوب مبيعات مرتبط بمندوب، مع تقييد الوصول على فواتيره.
- تبويب المستندات.
- حركة البضاعة.
- التسلسل من رقم البداية إلى أعلى رقم موجود، وإدخال فاتورة قديمة لاحقًا، والإخفاء الأسبوعي.
- استلام أصل الفاتورة أثناء وجود مهمة أخرى معلقة للتأكد من استقلال العمليات.

## ملاحظات التوافق
- ضغط الصور وتجهيزها قبل الرفع مستمر من النسخة السابقة.
- النماذج الجديدة تستخدم نفس مسار ضغط الصور.
- CSS يحتوي على تصميم Responsive للشاشات الصغيرة، والجداول/البطاقات مصممة للجوال واللابتوب.
