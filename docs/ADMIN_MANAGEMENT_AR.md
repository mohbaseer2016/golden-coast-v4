# إدارة الأصناف والسيارات والمستخدمين

- الأصناف: تعديل الاسم والوحدات، تفعيل/تعطيل، حذف إذا لم يستخدم سابقًا. إذا كان مستخدمًا، يتم تعطيله لحماية السجلات.
- السيارات: تعديل البيانات والحالة، تفعيل/تعطيل، حذف إذا غير مستخدمة، وإلا تعطيل فقط.
- المستخدمون: توقيف/تفعيل الدخول، وتغيير الصلاحيات. المدير الرئيسي admin لا يمكن تعطيله أو حذفه.
- الحذف المنطقي يحافظ على الفواتير والسجلات التاريخية.
