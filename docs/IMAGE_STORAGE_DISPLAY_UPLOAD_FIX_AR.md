# إصلاح عرض وربط ورفع الصور

## ما تم إصلاحه
- إعادة حقل رفع صورة أصل الفاتورة إلى شاشة الموارد؛ كان قد اختفى في تحديث سابق رغم بقاء الحقل في قاعدة البيانات.
- صورة أصل الفاتورة تُضغط قبل الرفع مثل بقية الصور.
- عند وجود رابط صورة قديم، لا يُطلب رفع نسخة جديدة ولا يُنشأ ملف مكرر.
- للفواتير القديمة التي رابطها مفقود من قاعدة البيانات، يبحث النظام عن الملف الموجود أصلًا في مجلد الفاتورة داخل Supabase Storage ويعيد ربط الرابط فقط، دون نسخ أو إعادة رفع الملف.
- فتح الفاتورة من البحث/الأرشيف يعرض جميع صور العملية المتوفرة: الأصل، استلام العميل، الناقل، السحب من العميل الأول، المرتجعات، ومستند المخزن.
- دعم صور الجوال التي يرسلها بعض المتصفحات بنوع MIME عام إذا كان امتداد الملف صورة معروفة.

## توفير مساحة Supabase
عملية استعادة الروابط القديمة تستخدم Storage List للقراءة فقط ولا ترفع أو تنسخ الصور.
الرفع الجديد يحدث فقط عند اختيار المستخدم ملفًا جديدًا مطلوبًا للعملية.
