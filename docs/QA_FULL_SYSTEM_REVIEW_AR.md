# مراجعة QA شاملة للنظام

تم فحص ملفات Python وJavaScript وربط الشاشات والنماذج بالـ API.

إصلاحات تمت أثناء المراجعة:
- إصلاح تحميل بيانات المناديب في الواجهة.
- إضافة شاشة إدارة المناديب للأدمن مع إضافة/تفعيل/توقيف.
- إصلاح خطأ قسم «حركة البضاعة» بسبب دالة تاريخ غير موجودة.
- إضافة عرض اسم «محاسب المبيعات» في المستخدمين وخيارات إنشاء/تعديل المستخدم.
- منع seed users من إعادة تفعيل المستخدم أو إعادة كلمة مروره عند كل Deploy.
- تسجيل مستخدم المخزن الذي نفذ التحميل.
- فرض صنف + وحدة + كمية عند «تم التحميل ناقص» من الواجهة والخادم.
- فرض تفاصيل المرتجع عند «تم جزئي/رفض كامل» من الواجهة والخادم.
- جعل صورة الاستلام إلزامية في اعتماد السائق حتى عند تنفيذ العملية من الأدمن.
- تسجيل تاريخ ومن استلم أصل الفاتورة لاستخدامه في حركة البضاعة.
- تقييد عرض حركة الفاتورة للسائق على فواتيره فقط.
- جعل إعداد تسلسل الفواتير خاصًا بالأدمن ومحاسب المبيعات.
- إضافة FINAL_REVIEW_PENDING إلى عداد/نافذة المستندات.
- الحفاظ على توافق الجوال واللابتوب.
