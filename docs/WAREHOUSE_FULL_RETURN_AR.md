# مرتجع كامل من المخزن

- خيار جديد: **مرتجع كامل من المخزن**.
- لا يتم اختيار سائق أو سيارة ولا تظهر الفاتورة للسائق.
- سبب المرتجع إجباري.
- صورة مستند المرتجع التي يرفعها أمين المخزن إجبارية.
- يظهر المستند ضمن مستندات المرتجعات وحركة البضاعة.
- ينتقل اعتماد المردود إلى محاسب المبيعات، واستلام أصل الفاتورة/المستند إلى الموارد كمسارين مستقلين قبل الإقفال.
