# طرق التوصيل والاستلام
- سائق الشركة: يختار المخزن السائق والسيارة، والسائق يرفع صورة الاستلام.
- سائق خارجي: لا سيارة من الشركة، وبعد التحميل تنتقل الفاتورة للموارد لرفع صورة الاستلام واعتماد نتيجة التسليم.
- العميل نفسه: لا سائق ولا سيارة، وأمين المخزن يجب أن يرفع صورة الاستلام قبل الاعتماد، ثم تنتقل الفاتورة للموارد.
