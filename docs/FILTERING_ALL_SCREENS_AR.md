# الفرز والفلترة في جميع الشاشات

تم توحيد البحث والفرز/الفلترة في:
- الفواتير المعلقة
- البحث والأرشيف
- المستخدمين
- السيارات
- الأصناف
- سجل الحركات
- نوافذ مربعات لوحة التحكم (مخزن/سائقين/مرتجعات/مستندات/مكتملة)

الفلترة تتم داخل الشاشة بدون إعادة تحميل الصفحة، مع ترتيب حسب الأعمدة المناسبة لكل شاشة.
