# V4 السحابية — ما تم تجهيزه

هذه النسخة مبنية من V4 وتحافظ على الصلاحيات ومسار الفاتورة والمستخدمين والسيارات والسائق الخارجي.

## الجديد
- قاعدة البيانات تقرأ من `DATABASE_URL`، لذلك تعمل مع Supabase PostgreSQL.
- الصور ترفع إلى Google Drive عند ضبط متغيرات Google، وتعود للتخزين المحلي فقط أثناء التجربة.
- الصور تضغط تلقائيًا قبل الرفع.
- مجلدات Drive تنشأ: السنة / الشهر / رقم الفاتورة.
- ملف `render.yaml` للنشر على Render.
- مسار فحص `/health`.

## المطلوب عند فتح اللابتوب
1. إنشاء مشروع Supabase ونسخ رابط PostgreSQL.
2. إنشاء مجلد Google Drive.
3. إنشاء Service Account وتفعيل Drive API.
4. مشاركة مجلد Drive مع بريد Service Account كمحرر.
5. حفظ ملف JSON سرًا وعدم رفعه إلى GitHub.
6. وضع القيم في Render كمتغيرات وSecret File.

## تنبيه
هذه حزمة الربط السحابي الأولى. يلزم اختبار عملي بعد وضع بيانات Supabase وGoogle Drive قبل استخدامها الفعلي من الموظفين.
