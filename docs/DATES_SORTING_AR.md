# تحديث التاريخ والفرز

في شاشة الفواتير المعلقة:
- إضافة عمود تاريخ الفاتورة.
- إضافة عمود تاريخ التحميل.
- إذا لم تحمل الفاتورة بعد، يبقى تاريخ التحميل فارغاً.
- يمكن اختيار حقل الفرز.
- يمكن اختيار الاتجاه: الأحدث/الأكبر أولاً أو الأقدم/الأصغر أولاً.
- القيم الفارغة تبقى في نهاية القائمة.

تم تطبيق اتجاه الفرز كذلك على شاشة البحث/الأرشيف.
