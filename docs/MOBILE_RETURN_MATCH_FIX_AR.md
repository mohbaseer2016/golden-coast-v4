# إصلاح مطابقة المرتجع على الجوال

سبب المشكلة:
واجهة المرتجع كانت تعرض اختيار «مطابق / غير مطابق»، لكن قيمة الاختيار لم تكن تُحوّل إلى `issue_results_json` قبل إرسال النموذج. لذلك السيرفر يستقبل قائمة فارغة ويعيد رسالة «يجب عمل مطابقة».

الإصلاح:
- تجميع مطابقة كل صنف عند الضغط على التأكيد، وليس الاعتماد على حدث change فقط.
- إرسال `match=true/false` لكل صنف مع رقم الصنف.
- عند غير مطابق، تصبح الكمية الفعلية مطلوبة.
- يعمل بنفس الطريقة على الجوال واللابتوب.
