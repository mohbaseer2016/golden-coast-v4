# مراجعة شاملة لرفع الصور والأداء
- إصلاح خطأ الحقل الرقمي الفارغ عند «العميل نفسه».
- تجهيز وضغط الصور فور اختيارها بدل الانتظار بعد الضغط على اعتماد.
- تخزين الصورة المضغوطة مؤقتًا وإعادة استخدامها عند الاعتماد.
- ضغط عدة صور بالتوازي.
- عدم إعادة ضغط JPEG صغير على الخادم.
- دعم HEIC/HEIF عبر pillow-heif.
- استمرار تعطيل زر الاعتماد أثناء الطلب لمنع التكرار.
- نفس مسار التحسين للمخزن والسائق والخارجي والمرتجع والإقفال وتعديل السائق.
- التعديلات لا تغيّر تصميم Responsive للجوال واللابتوب.
