# متابعة أصل الفاتورة عند الموارد

التعديل محدود على شاشة الموارد فقط:
- صورة استلام العميل تبقى مسؤولية السائق/المندوب حسب مسار الفاتورة.
- إذا كانت صورة الاستلام موجودة فلا يطلب من الموارد رفعها مرة أخرى.
- الموارد تختار فقط: هل تم استلام أصل الفاتورة؟ نعم / لا.
- اختيار «لا» يحفظ المتابعة وتبقى الفاتورة معلقة.
- اختيار «نعم» يسجل اسم مستخدم الموارد والتاريخ والوقت ويكمل مسارات الإقفال الأخرى.
- لم يتم تغيير مسارات المخزن أو المرتجعات أو المندوب أو السائق الخارجي أو تحويل عميل إلى عميل.
